# php2shell by hashsec: 

This works on default stock PHP images:
- 8.5.11 (arm64 / amd64)
- 8.3.35 (arm64 / amd64)
- 8.4.26 (arm64 / amd64)
- 8.5.4 (arm64 / amd64)

These images come with `display_errors` enabled by default. For configurations where `display_errors` is off, we will release separate code soon, we do not yet have it working reliably across different PHP versions and are still experimenting.

Support for PHP using the PHP-FPM SAPI is also in progress and will be released soon, as cross-version support is still being developed.
